# Ford Car Price Prediction using Streamlit

## Project Title
Ford Car Price Prediction Web Application

## Objective
To predict the selling price of a Ford car using a Machine Learning Linear Regression model and a Streamlit web application.

## Tools & Technologies
- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## Files
- app.py
- car_price_dataset.csv
- LR_car.pkl
- scaler.pkl
- columns.pkl

## Features
- User-friendly Streamlit interface
- Numerical input fields
- Dropdown selection for categorical data
- Car model name input
- Predict button
- Displays predicted car price

## How to Run
1. Open the project folder in VS Code.
2. Open Terminal.
3. Run:
   ```
   streamlit run app.py
   ```
4. Open the Local URL displayed in the terminal.

## Output
The application predicts the selling price of a Ford car based on the user inputs.
